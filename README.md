## ✨ Features

- 📊 **Live Spreadsheet Lead View**: Real-time Google Sheets-style interactive data grid with sticky headers, contact numbers, official emails, decision makers, and ratings.
- ⚡ **100% Free Live Web Scraper**: Search any city or shop category worldwide (e.g. `karur shops`, `puliyur shops`, `trichy hotels`, `salem textiles`, `coimbatore hospitals`) with zero API fees or credit card requirements.
- 📋 **Google Search & Maps Text Scraper**: Copy raw output text from Google Search / Maps and click **Import Text** to instantly parse business names, phone numbers, ratings, review counts (`8.1K`, `1K`), and street addresses.
- 🗺️ **GPS Location & Plus Code Geocoder**: Converts Google Plus Codes (`W4QW+FG3`, `X34G+VG9`) and street landmarks into real-world map coordinates and pins them on Leaflet maps.
- 💼 **B2B Lead CRM Pipeline**: Track sales stages (*New Prospect*, *Contacted*, *Follow Up Needed*, *Hot Prospect*, *Deal Closed*) and save call notes per client.
- 📥 **1-Click Excel / CSV Exporter**: Export selected or full lead lists to downloadable `.csv` spreadsheets with UTF-8 encoding.
- 📱 **Outreach Action Bar**: Direct 1-click `tel:` phone call links, `mailto:` email links, and pre-formatted WhatsApp sales pitch links.

---

## 🛠️ Technology Stack

- **Frontend**: Vanilla JavaScript (ES6+), HTML5, CSS3 (HSL Token Design System)
- **Bundler & Server**: Vite 8
- **Interactive Maps**: Leaflet.js & OpenStreetMap
- **Icons & UI**: Custom HSL Responsive Grid & SVG Icons
- **Data Persistence**: Browser `localStorage` for CRM Leads

## 🚀 Quick Start

### 1. Clone Repository
```bash
git clone https://github.com/Mukil630/Lead-Collector.git
cd Lead-Collector
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Run Local Dev Server
```bash
npm run dev
```
Open **`http://localhost:5173/`** in your browser.

### 4. Build for Production
```bash
npm run build
```

## 📖 How to Use

1. **Live Search**:
   - Type any location or business query in the search bar (e.g. `salem textiles`, `puliyur shops`, `trichy hotels`).
   - The live web scraper automatically generates 30+ B2B leads in the right spreadsheet view.

2. **Google Text Scraping**:
   - Copy any search results text from Google Search or Google Maps.
   - Click **📋 Import Text** in the header or paste it into the main search bar to extract phone numbers & shop leads.

3. **Exporting Data**:
   - Click **📥 Download Excel / CSV** or **Export CSV** to download all collected leads into an Excel spreadsheet.
